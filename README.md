# SQL Query Helper

## Project Overview
SQL Query Helper is a Python-based application that helps users interact with a database using simple English questions. It aims to make database querying easier by converting natural language questions into SQL queries.

## Features
- Ask questions in simple English.
- Generate SQL queries.
- Connect to a MySQL database.
- Execute SQL queries and display results.
- Simple Streamlit user interface.

## Technologies Used
- Python
- MySQL
- Streamlit
- LangChain
- SQLAlchemy

## Project Workflow
1. Ask a question.
2. Generate an SQL query.
3. Execute the query.
4. Display the result.

## Project Files
- `app.py` – Main application.
- `database.py` – Database connection.
- `sql_generator.py` – SQL query generation.
- `requirements.txt` – Project dependencies.
- `.gitignore` – Excludes private and unnecessary files.

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure your local database and environment variables.
4. Run the application using `streamlit run app.py`.
